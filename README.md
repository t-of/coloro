# coloro — 色の山で競う2人用パズル

6色の駒を取り合って一番高い山を作る対戦ゲーム。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/coloro/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1 台の端末を 2 人で交代して遊ぶか、CPU と対戦します（CPU はプレイヤー2。αβ 探索で読み、終盤は最後まで読み切る）。6 色×6 枚の駒を 6×6 の盤にランダムに並べます。

- **準備**: 先手でないプレイヤー（プレイヤー2）が好きな駒を 1 枚取り、そのマスに矢印コマを置きます。矢印の向き（縦 ↕ / 横 ↔）もここで選びます。そのあとプレイヤー1 から手番です。
- **手番**: 矢印コマを、矢印の向き（縦なら今の列、横なら今の行）に沿ってどちらへでも好きなだけ動かし、駒のあるマスに止まってその駒を取ります（途中のマスは駒があってもなくても飛び越えられます。空きマスには止まれません）。動かしたあと、矢印は 90° 回ります。
- 取った駒は色ごとに自分の前に積みます。その色の山があればそこへ、新しい色なら自分の山の列の左端か右端のどちらに置くか選びます（最初の 1 山は選びません）。
- 手番のプレイヤーが動かせる先（矢印の向きの線上に駒）がなければ、そこで終わりです。
- **勝敗**: 一番高い山（色は問わない）が高い方の勝ち。同点なら一番左の山の高さ、それも同点なら左から 2 番目…と比べます（山がない位置は 0 段）。全部同じなら引き分け。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```
